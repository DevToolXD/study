# 공부방

책 사진으로 만든 문제를 푸는 공부 앱. Safari에서 **홈 화면에 추가**해서 쓰는 PWA이고, **폰 하나로 다 한다.**
문제는 폰의 **Claude 앱**(Code)에서 책 사진을 올리면 Claude가 이 저장소에 직접 넣는다. 앱에서 문제를 하나하나 쓸 일은 없다.

```
폰의 Claude 앱 ── 책 사진 첨부 ──> Claude Code 세션 ──> data/library.json ──push(master)──> GitHub Pages ──> 공부방이 자동으로 가져옴
```

복사나 붙여넣기는 없다. 문제는 저장소의 `data/library.json` 한 파일로만 오간다.
Claude Pro로 로그인한 Claude 앱 안에서 돌아가서 **API 키도 API 비용도 없다.** 공부방 앱은 AI를 부르지 않고, Claude 계정 정보나 API 키를 받지 않는다.

## 1. 앱 쓰기

1. 이 저장소의 GitHub Pages 주소를 Safari로 연다. (Settings → Pages → Branch `master`, `/ (root)`)
2. 공유 버튼 → **홈 화면에 추가**.
3. 앱에서는 **과목과 시험·단원 이름만** 만든다. 문제는 아래처럼 사진으로 채운다.

앱은 켤 때마다(그리고 홈 화면 앱으로 돌아올 때마다) 새 버전과 새 문제를 확인한다. 바뀐 게 있으면 알아서 새로고침하고,
퀴즈를 푸는 중이면 끝난 뒤에 적용한다. 바로 확인하고 싶을 때만 설정의 **지금** 버튼을 쓴다.

## 2. 폰에서 사진으로 문제 만들기

**처음 한 번만**

1. Claude 앱을 설치하고 Claude Pro 계정으로 로그인한다.
2. Claude 앱의 Code 화면에서 GitHub를 연결하고, 이 저장소(`DevToolXD/study`)를 허용한다.

**만들 때마다**

1. 공부방의 **문제 만들기**(홈 화면 오른쪽 아래 반짝이 버튼)에서 과목, 시험·단원, 종류, 개수(50·100·150)를 고른다.
2. **Claude 앱에서 사진 올리기**를 누른다. 저장소가 골라지고 메시지가 채워진 채로 Claude 앱이 열린다. (같은 메시지는 클립보드에도 복사된다.)
3. Claude 앱에서 **+ 버튼으로 책 사진을 골라** 메시지와 함께 보낸다.
4. Claude가 사진을 읽고 **기본 150개**를 만들어 `data/library.json` 에 넣고 `master` 로 push 한다.
5. 공부방으로 돌아오면 새 문제가 들어온다. "Claude가 문제를 만드는 중이에요" 카드가 기다리는 동안 12초마다 확인하고, 도착하면 알려 준다.

과목과 시험은 **이름이 같으면** 앱에서 만든 것에 합쳐진다. 문제 만들기 화면이 쓰는 링크는 Claude 앱의 공식 딥링크다(`https://claude.ai/code/new?repo=…&branch=master&q=…`, 앱이 없으면 `claude://` 버튼).
컴퓨터에서 쓸 때는 저장소 폴더에서 `claude` 를 열고 `/quiz 수학 3단원 사진경로...` 로 불러도 된다.

과목 성격에 맞춰 만든다.

| 과목 | 만드는 것 | 앱에서 푸는 방식 |
|---|---|---|
| 영어·일본어 등 단어 | 사진에 있는 단어 전부 | 뜻 고르기, 단어 고르기, 직접 쓰기를 순서대로 |
| 수학 | 같거나 비슷한 유형의 문제를 숫자와 상황을 바꿔 | 직접 쓰기(주관식)와 객관식 |
| 사회·역사·과학 등 | OX, 객관식, 주관식 퀴즈 | OX 버튼, 보기 고르기, 직접 쓰기 |

모든 문제에는 **유형(topic)** 이 붙는다.

### 왜 앱 안에서 바로 올리지 않나

- 웹앱이 Claude Pro 로그인을 받아서 쓰는 공식 방법이 없다. 구독 로그인(OAuth)은 Claude 앱과 Claude Code 용으로만 허용된다.
- Claude Code의 루틴 호출 API(`/v1/claude_code/routines/{id}/fire`)는 브라우저의 CORS 사전 요청을 받지 않아서 웹앱이 직접 부를 수 없다.
- 이 저장소는 공개라서 책 사진을 저장소나 GitHub 이슈에 올릴 수 없다.

그래서 사진은 Claude 앱 안에서만 오가고, 공부방에는 만들어진 문제만 들어온다.

## 3. 앱이 문제를 내는 방식

- **많이 틀린 유형은 더 자주**, 잘 맞히는 유형은 덜 나온다. 시험 화면의 **유형** 탭에서 유형별 정답률과 다음 연습의 출제 비중을 볼 수 있다.
- 한 문제를 **6번** 풀고 마지막에 맞히면 **정복**으로 빠진다. 단어는 2번씩 방식을 바꿔 가며 6번이다.
- 남은 문제가 적어지면 시험 화면이 새 문제를 받을 때라고 알려 준다. **새 문제 받기**를 누르면 같은 시험에 새 150개를 요청하는 메시지로 Claude 앱이 열린다.
  기존 문제는 지우지 않고, 기기에서 정복한 것은 앱이 알아서 뺀다.
- 한 번에 푸는 문제 수(10·20·30·50·100·150)는 설정에서 바꾼다.

스크립트를 직접 쓸 수도 있다.

```bash
node tools/quiz.mjs add --subject "수학" --exam "3단원" --kind math --target 150 < questions.json
node tools/quiz.mjs list --topics
node tools/quiz.mjs remove --subject "수학" --exam "3단원" --question "기울기"
node tools/quiz.mjs validate
```

## 4. 화면

- 모든 면이 **리퀴드 글라스**다. 과목 색이 번지는 배경 위에 툴바, 탭바, 카드, 문제, 시트, 메뉴, 토스트가 유리처럼 떠 있고, 글자는 그 위에서도 읽히는 색을 쓴다.
  글래스 위에 글래스를 겹치지 않고(안쪽은 반투명 채움), 긴 목록은 행마다 흐리지 않고 카드 하나만 쓴다.
- 움직임은 스프링이다. 화면은 쌓이듯 밀려 들어오고, 시트는 끌어 내려 닫고, 탭과 분할 버튼의 하이라이트는 미끄러지고, 답을 고르면 그 자리에서 색이 바뀌며 해설이 펼쳐진다.
  기기의 "동작 줄이기"를 켜면 짧은 페이드만 남는다.
- **폭 320px(iPhone 화면 확대)부터** 맞춰져 있다. 좁은 화면(세로 폰)은 아래 탭바, 640px 이상(가로 폰, 태블릿)은 옆으로 옮겨진 세로 바(iPhone Duo처럼), 1000px 이상은 사이드바가 있는 레이아웃이다.
- 디자인 규칙은 [liquid-glass-skill](https://github.com/heyparsadev/liquid-glass-skill)을 웹(CSS)에 옮긴 것이다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `styles.css` | 화면 틀과 디자인 시스템(글래스, 스프링 모션) |
| `engine.js` | 저장, 출제 가중치, 정답 판정, 라이브러리 병합. DOM 없음 |
| `kit.js` | DOM 도우미와 모션 도구(`anim`, `rise`, `reveal`, `burst`…) |
| `app.js` | 화면, 시트, 라우터, 동기화, 자동 업데이트, 문제 만들기 |
| `icons.js` | 손으로 그린 SVG 아이콘 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 앱, 오프라인, 자동 업데이트 |
| `data/library.json` | Claude가 쓰고 앱이 읽는 문제 파일 |
| `tools/quiz.mjs` | 문제 검증, 중복 제거, 병합 |
| `.claude/skills/quiz`, `CLAUDE.md` | Claude가 따르는 절차 |
